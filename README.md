## Featured Project

### 01. Enterprise Network Segmentation & Security Architecture

**Security Architecture | Network Segmentation | Firewall Security | Risk Assessment**

An end-to-end security architecture case study combining a fictional enterprise network redesign with a practical segmentation laboratory built using **OPNsense, Debian Linux, Kali Linux, and Oracle VirtualBox**.

The project covers security requirements, architecture assessment, traffic flow analysis, risk evaluation, firewall policy design, architecture decisions, and security validation.

### Key Achievements

- Designed and implemented three isolated security zones: **Application, Database, and Management**.
- Configured least-privilege firewall policies using OPNsense.
- Executed **5 network connectivity validation scenarios**, with 4 passing and 1 partially evidenced.
- Identified unintended access to the firewall management interface caused by an automatic anti-lockout rule.
- Remediated the issue and verified that authorized administrative access remained available.
- Developed **10 structured security architecture documents**, including a risk register, Architecture Decision Records (ADRs), and a Requirements Traceability Matrix (RTM).
