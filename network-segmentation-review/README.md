
# Network Segmentation & Traffic Flow Security Review

## Overview

A practical security architecture case study focused on evaluating network segmentation, communication paths, and security controls.

## Objectives

- Identify unnecessary communication between security zones.
- Review firewall access requirements.
- Evaluate remote access security risks.
- Recommend improvements based on least privilege and defense in depth.

## Scope

This project uses a fictional network environment for educational and portfolio purposes.

## Project Deliverables

- Network architecture diagram
- Traffic flow analysis
- Security risk assessment
- Recommended security architecture
- Security design review findings
