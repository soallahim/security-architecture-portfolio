
# Enterprise Network Security Architecture
## Assessment & Redesign

### Project Overview

An end-to-end security architecture case study demonstrating how to assess, redesign, and validate the security of a fictional enterprise network.

The project focuses on identifying architectural security risks, evaluating existing security controls, and developing a risk-driven security architecture aligned with business and security requirements.

### Key Objectives

- Assess the existing enterprise network architecture.
- Identify security design weaknesses and unnecessary traffic flows.
- Evaluate network segmentation and firewall access controls.
- Perform a structured security risk assessment.
- Develop an improved security architecture.
- Document security design decisions and trade-offs.
- Define validation methods for the proposed security controls.

### Project Deliverables

- Current Network Architecture
- Security Requirements
- Traffic Flow Matrix
- Security Assessment Findings
- Risk Register
- Proposed Secure Architecture
- Architecture Decision Records
- Security Validation Plan

### Methodology

1. Define business and security requirements.
2. Review the existing architecture and communication flows.
3. Identify security gaps and assess associated risks.
4. Develop a risk-based architecture redesign.
5. Document design decisions and recommended controls.
6. Define validation activities and acceptance criteria.
